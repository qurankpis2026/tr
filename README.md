# مُعِين التَّرْتِيل

مُسمِّع ذكي لحفظ القرآن الكريم: يتعرّف على السورة من تلاوتك، ويسألك «هل أذكرك؟» عند التوقف، ويلوّن الكلمات (أسود: قرأتها، برتقالي: تذكّرتها بعد تردد، أحمر: ذكّرك بها)، مع مكتبة القراءات السبع، وعدّاد الأذكار بالصوت، ووضع «AI يسمع لي».

## هيكلة الملفات

```
index.html               ← الصفحة الرئيسية (يفتحها GitHub Pages تلقائياً)
manifest.webmanifest     ← بيانات التطبيق عند إضافته للشاشة الرئيسية
.nojekyll                ← يمنع GitHub من معالجة الملفات (لا تحذفه)
assets/
  css/app.css            ← التنسيقات
  js/app.js              ← كود التطبيق
  icons/                 ← الأيقونات (المتصفح + الآيفون)
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً (Public) باسم مثل `mueen-tarteel`.
2. **Add file → Upload files**، واسحب **محتويات** هذا المجلد (وليس المجلد نفسه) ثم **Commit changes**.
3. **Settings → Pages**، وتحت Branch اختر `main` والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة أو دقيقتين يصير الرابط: `https://اسم-حسابك.github.io/mueen-tarteel/`

> ملاحظة: ملف `.nojekyll` يبدأ بنقطة فقد يكون مخفياً في جهازك. لو ما انرفع، ما يضر التطبيق.

## الاستخدام على الآيفون

- افتح الرابط في **سفاري** واسمح بالميكروفون والتعرّف على الكلام.
- للإضافة للشاشة الرئيسية: زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## مفتاح Gemini

ميزات التحليل و«AI يسمع لي» تحتاج مفتاح Gemini من Google AI Studio. يُدخل من الإعدادات (⚙) داخل التطبيق، ويُحفظ في متصفح كل مستخدم فقط — **لا يوجد أي مفتاح داخل ملفات المستودع**.

## التحديث

عند وجود نسخة جديدة: ارفع الملفات الجديدة بنفس الطريقة فوق القديمة (نفس الأسماء والمجلدات) — GitHub يستبدلها تلقائياً.
